单 npm 包 `@xrn1997/dsh-session-delete`，通过 Cordis 机制注入宿主：`cordis.patch.yml` 以 `insert` 形式注册插件 ID；`package.json` 的 `exports` 暴露 `.`（Node 侧入口）、`./client`（浏览器侧入口）以及 `./locale/*.json` 多语言文件。构建产物输出到 `lib/`（由 `tsdown` 构建，见 scripts），源码在 `src/`，测试在 `tests/`。Vitest 采用双 project 模式：`node` 环境跑 Node 半用例，`jsdom` 环境跑浏览器 UI 用例，不再使用 alias 替身，因为控件已内聚于 `src/client/ui/*`。宿主集成元数据集中在 `package.json` 的 `dsh` 字段：`bundle.patch` 指向 patch 文件、`client.inject` 声明注入 locale、`compatibility.dshReleases` 声明实测兼容的 DSH 版本（0.2.0-rc.2）。依赖方向单向向外：插件依赖宿主提供的 `@deepseek-ai/cordis` 与 React，不反向引入宿主实现。
