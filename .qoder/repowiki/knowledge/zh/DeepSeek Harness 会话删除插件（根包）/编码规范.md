- 浏览器端与 Node 端的测试用例按目录分离（`tests/*.test.ts` 走 node 环境，`tests/client/**/*.test.{ts,tsx}` 走 jsdom 环境），由 vitest.config.ts 的双 project 配置强制区分。
- 宿主兼容性通过 `package.json` 的 `dsh.compatibility.dshReleases` 显式列出实测版本，而非依赖 peerDependencies 范围来推断运行时能力。
- UI 控件与图标内聚于 `src/client/ui/*`，不再通过 alias 替身外部库，避免 alias 掩盖导出缺失问题。
