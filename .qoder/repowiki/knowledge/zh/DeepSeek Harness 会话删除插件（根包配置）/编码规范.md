- 浏览器端 bundle 的模块纯度由构建期 `gateClientImport` 强制校验：除 React 家族三个平台模块外，禁止任何 `@deepseek-ai/*` 或 Node 内建进入浏览器产物。
- 跨宿主平台的依赖通过 tsdown 的 `neverBundle` / `alwaysBundle` 谓词显式分流，而非依赖默认行为；平台相关模块一律走宿主注入的 require。
- DSH 兼容性分两层声明：`engines.dsh` 控制装包时的版本窗口，`dsh.compatibility.dshReleases` 单独记录桌面真机实测通过的宿主版本族。
- 浏览器 UI 样式以真实 `.css` 文件形式存在，经自定义 tsdown 插件转成字符串并通过 `<style>` 注入，而不是使用 CSS-in-JS 或构建期内联。
