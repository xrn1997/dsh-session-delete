彻底删除 1 个会话？

/code-review
IRCamera · 删除于今天 13:05 · 224 KB

这会从回收站移除文件，之后没有任何副本可以恢复。

▸ 不做"输入会话名才能删"那种仪式；但这一步的按钮、文案、位置三处都要跟 ② 明显不同。

交互规则（UI 必须保住的逻辑）

  • 删除中该行**立即**从列表消失，不等磁盘操作完成；失败则回滚那一行并说明原因。
  • 正在运行的会话：菜单里「删除」置灰，hover 提示"会话正在运行，先停止再删除"。
  • 恢复后回到原项目下；原本是归档态的，恢复后仍在"已归档"里。
  • 恢复默认插到列表末尾（要原位就用账本序号，已单独记为可选项）。
  • 回收站入口常驻侧栏底部（邮件客户端"已删除"的位置）；入口本身始终在，只有计数角标在为空时隐藏。

落地时要对齐 / 待定

  • 配色、圆角、字号全部换成官方 `dsh-client-ui-primitives` 的 token —— 本稿只定结构与层级。
  • 「删除」菜单项挂 sidebar.workspaces.session.menu.item，位置随宿主既有菜单顺序，不自建菜单。
  • 回收站入口挂 sidebar.footer.action；完整面板要独立页面时再挂 settings.section。这两个槽位名是从宿主包的字符串里读出来的，不是官方文档列的清单——实现第一步用 ctx.slots.inject 各撞一次确认，撞不上会在插件激活时响亮失败。
  • 图标用官方图标集，不用本稿这些手绘 SVG。
