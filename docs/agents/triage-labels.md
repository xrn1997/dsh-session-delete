# Triage Labels

技能用五个规范 triage 角色说话。本仓直接采用默认标签串：

| 规范角色 | 本仓标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需评估此 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分定形，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时，直接用上表对应的标签串。
