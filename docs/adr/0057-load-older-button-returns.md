# 「加载更早」为什么回到工具栏、滚到顶为什么不再自动补页

Status: accepted

详情正文的工具栏左端重新常驻一颗「加载更早」：有更早页才出，点一次取一页；滚到顶不再发请求。右缘的提问轨照旧——跳得远的那句仍靠游标循环补页到它进窗，拿掉的只是「滚动本身算一次取数」这条隐式入口。

## 背景

ADR-0054 撤掉按钮时，把「连续往前读」交给「从下方滚回离顶很近就补一页」。它把两件不同的事绑在了同一个手势上：一件是「跳到很久以前的某一句」，另一件是「再往前读一页」。前一件已经由右缘的提问轨接住（点一格 → 补页到它进窗，全程一个动作）；后一件却被挂到滚动事件上——读者只要靠近顶端就替他取数，取完把新页 prepend 在头上、再按高度差把视口按回原处，**顶端于是后退了一页**。想往回拖滚动条找一个位置时，每接近顶端一次就多长一页：手柄持续变小、目标位置持续下移；长会话里就是「拉到底再回拉，拉半天都拉不回去」——整条历史在读者没要求的情况下被一段段取回来。

## 决定

1. **按钮回归工具栏左端**：`olderCursor` 非空时常驻；在飞时禁用并改说「正在加载更早…」；读失败原文落在同一行的 `role="status"` 里，正文仍是「有内容」。
2. **取数只由显式动作发起**：这颗按钮、切进简洁档时的那一次联动、提问轨上点某一格。滚动只管阅读——`src/client/use-detail-pager.ts` 的 scroll 监听与它的边界常量删除。
3. **提问轨不动**：右缘一句提问一格、悬停 / 聚焦出预览、点一下跳到那句；没加载的按 `olderCursor` 一页页补到它进窗，上限 `JUMP_PAGE_LIMIT`，超限只说一句「这句离现在太远，先点更近的一条」；落位只对齐、不画高亮框。跳转是读者点出来的动作，不是滚动的副作用。整条会话的提问索引仍随首次 `/detail` 过线（`src/shared/wire.ts` 的 `TrashDetailPromptWire`；本篇承接），后续分页不重复搬。详情保持期轨跟着上一条的帧顶住、整条禁用（ADR-0049），换到新详情才恢复。
4. **简洁档的自动连翻保留**：补回来的一页全是被藏起来的过程块时继续往前翻，直到出现对话内容、翻完或到 `AUTO_OLDER_PAGE_LIMIT`；触发源是按钮点击或切档，不再是滚动。prepend 后的滚动高度补偿不变——新页落在视口上方，读者往上滚就是读它。四档工作步骤见本篇「沿用」节；界面事实源是 `docs/ui-spec.md` ⑥。这一篇只动分页入口，不动档位与折叠语法。

## 沿用（原 ADR-0047 的档位决定）

本篇只动分页入口；工作步骤的档位仍是现行判据。ADR-0047 被 0054（再被本篇）取代后，保留项在这里自有正文：

- **四档**：简洁 / 标准 / 详细 / 完全展开；默认「标准」。
- **标准档**把连续的过程块收成一行（标签「工作步骤」+ 计数「N 步」），点开组后仍逐条折叠；**详细档**逐条列出、各自折叠；**完全展开** = 详细档 + 一次性铺开当前页所有过程块（之后仍可逐条收起）；**简洁档**只画用户提问与助手回答。
- **为什么是这四档**：过程块（思考、工具、注入、系统消息、压缩摘要）常比对话多；四档让读者按任务选「只看对话 / 看过程摘要 / 逐条看 / 全铺开」，不在一屏几十条折叠头里逐条点，也不被一次铺开的工具输出淹没。
- **不改的东西**：档位切换控件、折叠语法与「完全展开是一次性默认」的判据全按 `docs/ui-spec.md` ⑥；本篇不重开这些决定。

## 边界

- **不做「暂停自动加载」开关**：多一个要管理的控件，而默认值本身就是那个坏读法。
- **不做「只有拖滚动条时不补」的判据**：滚轮、触屏、键盘、无障碍滚动各有事件面，覆盖不全；而拖到顶正是最常见的触发姿势。
- **四档工作步骤见本篇「沿用」节**：这一篇只动分页入口，不动档位与折叠语法。

## 被否掉的替代

- **保留自动补页，另加一颗「暂停」**：读者得先发现开关、还得记得自己开过它；默认状态仍然是「滚到顶就替我取数」。
- **滚到底（尾部）才自动补**：尾部是最新内容，更早的页在上方；方向反了。
- **按钮只在滚到顶时出现**：有更早页时它该一直在；多一次显隐只是把读者推去猜。

## 后果

- `src/client/use-detail-pager.ts` 少了滚动监听与它的边界常量；`src/client/session-detail.tsx` 的工具栏恢复按钮；`src/client/copy.ts` 恢复 `detail.loadOlder` / `detail.loadOlder.loading`，`detail.compact.pageOnly` 说回「点『加载更早』」。
- 连续往前读回到「一次点击一页」；要一次跨很多页，走右缘的轨。
- 测试：`tests/client/trash-detail.test.tsx` 的「滚到顶自动补页」一组换成「点按钮才取数 + 不挂滚动监听」；`tests/client/trash-panel.test.tsx` 的补页触发改成点按钮。

锚点：`src/client/session-detail.tsx`；`src/client/use-detail-pager.ts` 的 `AUTO_OLDER_PAGE_LIMIT`；`src/client/use-prompt-rail.ts` 的 `JUMP_PAGE_LIMIT`；`src/client/use-detail-rail.ts`（两档共用的接线）；`src/client/prompt-rail.tsx`；`src/client/detail-pane.tsx` 的 `DETAIL_PANE` / `RAIL_GUTTER`；`src/client/copy.ts`；`docs/ui-spec.md` ⑥；`tests/client/trash-detail.test.tsx`；`tests/client/trash-panel.test.tsx`；`tests/client/prompt-rail.test.tsx`。ADR-0054 整篇由本篇取代。
