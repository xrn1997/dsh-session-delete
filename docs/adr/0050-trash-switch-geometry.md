# 切换不重排版面：预留滚动条槽、回顶与首帧前自动选中

Status: accepted

内容切换时最刺眼的不只是骨架，还有版面横向与纵向的跳动：滚动条槽出现或消失会让正文宽度变一次，换条目继承上一条的滚动偏移，宽档自动选中晚一帧才落地。决定把这些几何变化从切换路径里移走：两栏无条件预留滚动条槽，详情换条目回顶，宽档自动选中在首帧绘制前完成。

## 背景

宿主对同类问题有明确的先例：composer 座位给后到的统计行预留高度，视图标签之间无条件预留滚动条槽（曾因此修过一次 4px 横移）。回收站面板原先只在内容溢出时才出现滚动条；清单与详情的正文宽度随滚动条出现/消失跳变，长切短时还会继承上一条的滚动偏移，被浏览器 clamp 到中段。宽档首读完成后才选中第一条，右栏会先露一帧「未选中」。这些都是布局事实，不是动画能遮住的。

## 决定

1. **两栏无条件预留滚动条槽。** 清单与详情两个滚动容器都常驻 `scrollbar-gutter: stable`，即使当下不溢出也不收回槽位；滚动条出现/消失不改变正文宽度。
2. **换条目回到顶部。** 详情滚动容器只在**画着的条目 id 真的变了**时复位；首次挂载不复位，避免覆盖分页补偿的初始读数。保持期画的是上一条，id 未变时也不复位。
3. **宽档自动选中在首帧绘制前落地。** 首读完成且尚无**有效**选中（选中 id 在，但那一行已被清单换版收走也算没有）时，选中第一条要赶在首帧绘制前完成，不露「未选中」一帧；清场与自动选中同一帧收口（清场走 layout 阶段）。窄档不自动下钻。是否允许自动选中仍由面板按布局宽度给，控制器不认断点。

## 为什么值得一篇 ADR

这不是一行 CSS：它把「切换路径上的几何变化」收成不变量，清单与详情两处滚动容器、首帧选中与滚动复位必须同时成立；少一处，切换就会重新跳一次，且症状只在真实布局里出现。被否方案也都验证过，留在这里防下一次「只在溢出时预留」的回退。

## 边界

- 不做按条目的滚动位置恢复：本版只回顶，作为后续候选。
- 不加过渡动画；这里的判据是几何不变量，不是观感修饰。
- 首帧快照归 ADR-0048，详情保持归 ADR-0049；这篇只管「切换时版面不许重排」。

## 被否方案

- **只在溢出时预留滚动条槽**：滚动条一出现正文就横移，正是要消灭的那一帧。
- **按条目记住滚动位置**：多一份跨挂载状态，且条目被写动作清掉后还要清账；本版先回顶。
- **用淡入淡出遮住重排**：重排发生在布局层，淡出不能阻止宽度与偏移变化，只会把空窗拉长。
