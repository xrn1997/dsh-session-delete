# ADR-0073 — 会话目录搬移对瞬态占用做有界重试

Status: accepted

`sessions/` 与 `session-trash/` 之间的整目录 `rename` 在 Windows 上会因目录里有打开的文件句柄（宿主会话 / 日志、索引或杀软扫描）回 `EPERM` / `EBUSY` / `EACCES`。这是短命竞争而不是判据错误：同一次真机批量里一条成员被占用、另一条正常搬走。所以搬移加**有界小步重试**，耗尽后仍原样报错；其余错误一次都不重试。

## 背景

2026-11-26 的真机批量（两条独立会话）只成功了一条；把同一场景在隔离 home 里循环复现后拿到了信封原文：失败成员是 `sessiondelete/io` 的 `移动会话目录失败：Error: EPERM: operation not permitted, rename '…\sessions\…' -> '…\session-trash\…'`，另一条成员照常进回收站，界面按部分失败同屏报了两句。失败条留在原处、journal 没有搬动任何东西，状态是干净的。

这类占用通常只持续几十到几百毫秒；把它直接摊给用户会造出一次本可避免的失败与重试操作，而无限重试或复制降级又会把一次原子搬移变成挂起或半途而废。真机读数还表明它只发生在目录搬移这一件写（服务端纯 API 连压 60 轮零失败；UI 高频循环才命中一次），所以修复面只收在搬移本身。

## 决定

1. **重试归动词层的会话目录搬移**：新助手 `src/verbs/move-directory.ts` 的 `moveDirectoryWithRetry` 包住 `fs.rename`，删除与恢复的**正向搬移和回滚搬回**四个调用点统一接入。通用 `FsPort.rename` 保持原语，不藏重试。
2. **有界、只认瞬态码**：最多 3 次尝试（首发 + 两次重试），间隔 50ms / 150ms，只对 `EPERM` / `EBUSY` / `EACCES` 重试。目标已存在、跨卷 `EXDEV` 与其余错误都是判据错误，一次都不重试。
3. **失败面保持不变**：重试耗尽后原样抛最后一个错误；动词的 journal 照旧折成 `sessiondelete/io`，信封、文案、逐条失败与部分失败横幅都不改。UI 不需要知道重试存在。
4. **可测性**：等待函数与间隔是助手的可选注入位（生产不传，默认 `setTimeout` 与固定间隔）；单测钉住次序、次数与耗尽路径，动词回归钉住「成功落地不触发回滚」与「回滚搬回同样重试」。

## 边界

- **不是锁、不是退避框架**：不替代留出主视图 / 活体摘除（ADR-0008）；持久占用仍以原文失败并留在原处，交给用户重试。
- 只覆盖会话目录搬移；其它文件系统动作（读、删、目标检查）不套这一层。
- 不加「复制 + 删源」降级：那会把同卷原子搬移换成可能半途而废的复制（ADR-0008 的同卷前提不翻）。
- 不改批量调度与到达序链；重试发生在单条成员的一步写内部，同一时刻仍是一趟串行写的一部分。
- 不无限重试、不做指数退避、不把间隔暴露成用户可调项。

## 被否方案

- **把重试放进通用 `FsPort.rename`**：所有调用方都继承一套与自身语义无关的等待；重试策略属于会话搬移这个领域，不属于 fs 原语。
- **无限重试或长退避**：把持久占用从「一次失败」变成「一次挂起」，用户既看不到错也等不到结果。
- **复制 + 删源**：失去原子性，还要处理半复制、目标已存在与跨卷三件事；与「回收站必须与 sessions 同卷」的前提相抵。
- **客户端收到失败后自动重发**：会产生重复写与第二次真实搬移，信封才是这一趟的唯一结论。
- **失败成员静默跳过/排队**：批量语义变成「也许稍后」，界面上的成功与失败都不可再说清。

## 代价

- 持久占用时错误晚 200ms 才上屏；这是有界等待的代价，换来瞬态竞争不再变成用户可见失败。
- 间隔是固定的两档，不按错误码或平台分配置；真机上更长的占用仍会失败，需要用户重试或排查句柄持有者。

锚点：`src/verbs/move-directory.ts` 的 `moveDirectoryWithRetry` / `MOVE_DIR_RETRY_DELAYS_MS`；`src/verbs/delete-session.ts` 的 `memberMove`（正向搬移与回滚搬回两处）；`src/verbs/restore-session.ts` 的 `memberRestore`（正向搬回与回滚退回两处）；`tests/move-directory.test.ts`「EPERM 两次后成功…」「三次都被占用…」；`tests/delete-session.test.ts`「目录搬移遇瞬态 EPERM…」「清单失败回滚…」；`tests/restore-session.test.ts`「放回目录遇瞬态 EPERM…」「挂账本失败回滚…」；`docs/architecture.md` §4.2；`src/ports/fs-port.ts` 的 `rename`（重试边界与判据错误仍住原语）。
