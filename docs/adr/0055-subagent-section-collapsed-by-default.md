# 子会话段默认收起，标题排挂常驻计数徽标

Status: accepted

回收站详情的「子会话」段从逐条常显改成**默认收起成一条单行摘要条**，标题排另挂一颗常驻计数徽标（点它展开并滚回该段）。列表是导航、核对用的读数另有家，常态把版面让给正文；代价是核对要多点开一次。

## 背景

ADR-0029 把子会话的查看入口定在详情，并且当时逐条常显。落地后两股作用力对上了：这一段的用途是**删前核对**（永久删除按整组释放），核对是删除前那一刻的动作，不是读详情时的常态；而正文才是详情的主任务——逐条列表常驻在会话信息与正文之间，孩子多时即便展开体已经限高内滚，也固定吃掉一截纵向版面。同时「这条有几个孩子」本身是核对要的事实，收起列表不能把它一起藏掉。

会话信息那张表不受影响：它全是核对读数，默认就该看得见（`docs/ui-spec.md` 状态⑥）。要收的只是**列表**。

## 决定

1. **段头收成单行摘要条**：分支图标 + 「子会话」+ 品牌色实心计数徽标（孩子总数；超条数闸时徽标仍给实数，展开体另标总数）+ 这些孩子的清册大小合计 + 展开 chevron。展开才逐条列标题/大小/删除时间，展开体限高内滚（上限住 `src/client/subagent-section.tsx` 的 `SUBAGENT_RAIL`），条数再多也不撑爆正文。
2. **标题排挂常驻计数徽标**：滚进正文后「有几个孩子」仍可见，点它展开并滚回该段。删前核对的两个事实（有孩子、有几个）在收起态下都不断供。
3. **组语义住展开体**：「随本条一起恢复或删除」这句仍写在展开体里——收起态不重复说，组语义与单级导航见本篇「沿用」节，一概不动。

## 沿用（原 ADR-0029 的决定 1–3）

本篇只收起**列表**，孩子视图本身没有变；ADR-0029 已被本篇取代，下列三条仍是现行判据，在这里自有正文：

1. **孩子不占清单行，入口在父详情的「子会话」段。** 孩子没有清单行可配清册事实，清单选中、组动作与键盘 / 多选语义不必为它重定义。
2. **孩子身份随 `subagents` 过线，复用 `TrashEntryWire`。** 缺席 = 没有孩子，不是空数组；孩子不在客户端清单里，没有「按 entryId 与清单配对」那条路，所以清册事实只能随父详情过线。
3. **孩子视图是离清单的单级视图。** 从父详情点进孩子只下一级；返回回到清单选中那条的详情，清单选中一变即收掉。组语义（恢复 / 彻底删除按整组）不变。

## 代价

核对要多点开一次（或改看确认框念的整组释放量）。接受它，因为核对是删除前的短动作，而版面让位是每一次读详情都要付的。

## 被否方案

- **保持常显（ADR-0029 原状）**：孩子列表不是读详情时常看的东西，却每次固定挤走正文一截；常显买到的只是省一次点击。
- **只收列表、不挂标题排徽标**：滚进正文后就看不见「有几个孩子」，删前核对的事实断供，收起就变成藏。
- **把徽标做成跳转到确认框**：确认框念的是整组释放量，徽标要的是展开列表逐条看，两件事；让一个控件兼职两个落点会把点错的代价抬到危险动作附近。
