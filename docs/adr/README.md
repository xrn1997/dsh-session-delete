# 决策索引

每篇一个决定，只记**难逆 + 无上下文会让人惊讶 + 当初真有过替代方案**的那三类。写作规范与翻案口径见 `docs/adr/ADR-FORMAT.md`。

"某条语义归谁"的现状在 `docs/architecture.md` §4，不在这里重复；批次账与实测证据不再另存日志，历史留在 git。**现状以代码与 `docs/architecture.md` 为准**，本索引只回答「当初为什么这么定、被否掉的是什么」。
