# 决策索引

每篇一个决定，只记**难逆 + 无上下文会让人惊讶 + 当初真有过替代方案**的那三类。"某条语义归谁"的总体形状在 `docs/architecture.md`，不在这里重复；批次账与实测证据不再另存日志，历史留在 git。**现状以代码与 `docs/architecture.md` 为准**，本索引只回答「当初为什么这么定、被否掉的是什么」。

编号只追加、别重排（断号即有人抄不到那一页）。翻案怎么落字——推翻整篇标 superseded，还是只翻案个别条目就地补订正括注——口径住 `AGENTS.md`「真相在哪」，本仓先例见 ADR-0002 关于 `rollbackFailures` 合并归属的就地订正括注。
